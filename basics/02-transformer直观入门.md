# 02 Transformer 直观入门：全班一起传小抄

> 本篇面向读完 [01 什么是大模型](./01-什么是大模型.md) 的读者：你已经知道
> 大模型是「填下一个空」的机器，现在想看看这台机器内部长什么样。
> 读完你会获得：一张能手画的 Transformer block 结构图，以及用 60 秒向面试官

## 一、为什么不能把词装进袋子里

上一篇说过：模型填词靠的是压缩在参数里的概率模式。但光有参数不够——
模型还得先「读懂上下文」才能填对那个空。

先想象一种最笨的做法：给每个词发一张固定的「名片」（一个向量），
整张名片上写死这个词的所有信息，不管它出现在哪句话里。

问题来了——**同一个词在不同语境里是不同东西**：

- 「苹果发布了新手机」里的苹果 = 科技公司。
- 「我觉得这个苹果很甜」里的苹果 = 水果。

词袋式的固定名片没法同时画好这两个苹果。于是副标题就呼之欲出：
**模型需要「看一眼上下文」，把每个词的表示临时修正一下**——
在「手机」身边，苹果的向量该往「公司」那个方向挪一挪。

盯上下文这件事的主角，叫**注意力机制（Attention）**。

## 二、注意力：全班传小抄时，每人决定多看谁几眼

一句话理解注意力：

> 班上一群人同时做题，每人手里一张自己的草稿。
> 轮到你改答案时，你扫视全班的草稿一眼——**重点看几个人的，其余瞟一下**，
> 然后综合大家的内容，写出你这一题的修正版。
> 最后：每个人都做完修正，整个班的结果是「互相影响过」的草稿。

这里你能立刻体会两个要点：

1. 「多看你几眼」的偏好是基于**彼此有多相关**的——他不是随便看。
2. 每个词都在**同时**进行这件事，不是排队等前一题做完。

## 三、Q / K / V：三种身份的自我介绍

注意力机制把每个词的「名片」拆成三份角色，用三次小变换得到：

- **Query（我想找什么）**：你这题卡在哪、你想瞄哪类草稿。
- **Key（我是什么）**：你这张草稿的标签、你能帮到什么样的求助。
- **Value（我真正的内容）**：你这张草稿上的干货。

数学流程一句话：你的 Query 去和**所有人**的 Key 一一对照打分（点积越大
越相关），分数转化成权重，然后**用这些权重去对所有 Value 做加权求和**——
这就是你的修正版表示。

用一句话串起来：

```text
你的草稿 = Σ( 你和别人的相关度分数 ) × 别人的干货内容
```

拿开头的例子走一遍：「苹果发布了新手机」里，苹果的 Query 是「我想找讲
我身份的伙伴」，它的 Query 碰到 Key「手机」时得分爆表，于是它狠狠吸收了
「手机」的 Value——苹果的向量被拽向了「公司」这个方向。

> 进阶指针：点积为什么要除以 √d、相关度怎么通过 softmax 变权重、
> 为什么缩放的数学那么妙，全部在
> [llm基础/transformer与attention.md](../interview-questions/llm基础/transformer与attention.md)
> 的「√d_k 推导」一节（经典极高频题）。

## 四、多头注意力：多组人同时从不同角度传小抄

上面只讲了一组 Query/Key/Value。但一句话的相关性是立体的——
语法相关、指代相关、空间相邻相关、主题相关……

**多头注意力（Multi-Head Attention）**就是让 h 组人**同时**开工：
一组盯主谓搭配，一组盯指代消解，一组盯相邻短语，各干各的修正，
最后大家把结果拼起来再统一上交一份。

直觉类比：一个医生看片子只能看一个角度，把片子同时分给骨科、神经科、
内科三个专家，再汇总会诊。多头 = 起一个「分组会诊」的班子。

> 进阶指针：MHA 为什么省参数、怎么一步跑到 MQA/GQA/MLA（省显存演进史），
> 见 [transformer与attention.md](../interview-questions/llm基础/transformer与attention.md)
> 的 MHA→MLA 章节。

## 五、还剩三件小事：位置、残差、数值安全网

Transformer 除了注意力，还有三样装备摆正了才能成军：

1. **位置编码（Positional Encoding）**：模型同时看整句话，没有「顺序」
   这个天然感觉，必须显式把「我排第几个」写进每个词的向量里，
   否则「我打你」和「你打我」在它眼里是同一袋词。
2. **残差连接（Residual Connection）**：在注意力或 FFN 修正
   一个词的表示时，**原表示直接绕路加到新结果上**——保证「改错了也不至于
   丢原信息」，也是几十层网络能叠起来不塌方的关键保险丝。
3. **LayerNorm / RMSNorm**：每层后把数值重新归一到合理区间，
   防止越算越大/越算越小把网络压垮。想成「安检闸机」：每一层把客流
   重新数一遍、放回核定人流内，才放行去下一站。

> 进阶指针：RoPE 为什么统治位置编码、Pre/Post-Norm 怎么选、
> RMSNorm 为什么赢，见
> [位置编码与norm.md](../interview-questions/llm基础/位置编码与norm.md)。

## 六、FFN：注意力管「关联」，FFN 管「知识」

Transformer block 里除了多头注意力，还有一个看起来很朴素的部件叫
**前馈网络（FFN）**：对每个 token 的表示做一次独立的升维再降维
（中间还会过一次非线性激活）。

为什么说分工明确？直觉可以这么理解：

- **注意力管的是「关联」**——这个词该看上下文里谁、信息往哪边流。
  它是**动态**的，依赖当前句子内容。
- **FFN 管的是「知识」**——注意力把相关证据都拽到面前之后，
  FFN 把这些证据往参数里靠：查日内瓦公约、激活「哦这是在考我代码」的
  模板、调用背过的语法细节。它是**静态**的，相当于每一层的
  「知识点速查函数」。

所以这个搭配可以记忆成：**「注意力收集证据，FFN 调用知识下判断」**。

> 进阶指针：FFN 内部为什么升维四倍、SwiGLU 为什么统治现代 LLM、
> 以及「让每个 token 只路由进几个专家 FFN」的 MoE 思路，见
> [moe架构.md](../interview-questions/llm基础/moe架构.md) 开头。

## 七、为什么 Transformer 赢了 RNN：两行最关键的直觉

RNN 时代，词是一个一个「排队」处理的——第 100 个词要借助于第 99 个词
的「记忆」才能被理解。这带来两个致命问题：

1. **并行度差**：一个词一个词算，GPU 的一万张卡大部分时间在干等。
2. **长程依赖断**：句首的信息传到句尾，早就被稀释得面目模糊。

Transformer 直接把这俩问题一起干掉——**所有词两两直接对视（注意力），
训练时完整句子一起算**。于是 GPU 可以肆无忌惮地并行，模型可以肆无忌惮
地读长上下文。这就是 2017 年那篇《Attention Is All You Need》的全部
底气。

## 八、手画一个 Transformer Block 的数据流

把一个词向量 `x` 送进一个 block，数据流是这样的（Decoder-only 常见的
Pre-Norm 形态）：

```text
输入 x (一个词或一段来表示所有词)
  │
  ├─→ LayerNorm ──→ 多头注意力 ──→ （+） ←──┐
  │                                        │
  └────────────── 残差直通  ────────────────┘
                    │
                    ▼  ← 新的 x'
  ├─→ LayerNorm ──→ FFN ──────────→ （+） ←──┐
  │                                            │
  └────────────── 残差直通 ───────────────────┘
                    │
                    ▼
            输出 y（送进下一个 block）
```

一行口诀：**「先归一化 → 进注意力/FFN → 跟原材料相加 → 继续往下走」**。
把这一个 block 复制 30 到 100 层，堆在最底下的是 token 查表
（embedding），最顶上是「填下一个空的概率分布」——一个完整的 LLM 就堆出来了。

> [coding/模型手撕/手写attention.md](../coding/模型手撕/手写attention.md)
> 和 [coding/模型手撕/手写transformer组件.md](../coding/模型手撕/手写transformer组件.md)。

## 九、▶ 面试挂钩：60 秒讲清架构的标准答

被问「Transformer 架构讲一遍」，按这个顺序，困难度递增也稳：

1. **痛点起头**：「RNN 串行且长程依赖弱，Transformer 用注意力让任意两个
   词直接交互，天然并行。」
2. **核心机制**：「每个 token 拆出 Q/K/V，Q 与所有 K 算相关度 softmax 加权
   所有 V；多头是并行几路不同视角的注意力。」
3. **结构**：「一个 block = 多头注意力 + FFN，外面包着 Pre-Norm + 残差，
   N 层堆叠；Decoder-only 还加因果 mask 防止偷看未来。」
4. **工程嗅觉收尾**：「代价是 O(n²)，Inference 阶段靠 KV Cache 提速、
   FlashAttention 省显存、分流 MLA 继续压——这几处是现在面试真正的
   分岔口。」

第 4 点一出，面试官通常会顺着你的引线给你抛下一题，主动权就回到你手里。
