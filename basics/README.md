# 零基础入门（Basics）

> 本模块是「地基层」正文：面向**会写 Python、但完全没接触过 LLM** 的读者。
> 读完你会获得：大模型到底是什么、Transformer 长什么样、以及继续往仓库深处走
> 的路标。它对应 [学习路线图](../resources/学习路线图.md) 中的 **L0-L1 阶段**，
> 先把这里读完，再进路由图的正轨。

## 这个模块解决什么问题

仓库里大部分内容（面经复盘、八股详解、系统设计）默认你已经知道什么是
Transformer、什么是 token。零基础直接读会撞墙——新概念里套着新概念。

这里的文章刻意做得更通俗：

- 多用生活化类比，少堆公式（公式留给深水区文章）；
- 每篇开头有一句定位说明，说清楚「面向谁、读完得到什么」；
- 每篇结尾有「▶ 面试挂钩」和「延伸阅读」，告诉你面试怎么把这件小事讲漂亮、
  再往后应该去读仓库里的哪几篇深文。

## 怎么用好这个模块

- **按顺序读，别跳**：01 的概念会直接被 02 当常识用。
- **读不进去的地方先跳过去**：卡住于某个术语时，记住它，往后看示例，
  大多数术语会在第二次出现时自然变得好懂。
- **每篇末的「延伸阅读」不是可选作业**：入门篇只是路标，深度都在那些
  进阶文件里；本模块的目标是让你「读得动」它们。
- **面试前一天回来过一遍「▶ 面试挂钩」小节**：那些话术是为临场压缩时间
  设计的，平时理解、临场背诵。

## 学完之后怎么走

读完 01、02 后，你有两条主干道可选，详情见
[学习路线图](../resources/学习路线图.md)（含 L0-L5 阶段总表和两条岗位主线）：

- **Agent 开发线**：先补 [RAG](../interview-questions/rag/) 全链路，
  再进 [Agent](../interview-questions/agent/) 的 ReAct/记忆/上下文工程。
- **AI Infra 线**：从 [llm 基础](../interview-questions/llm基础/) 的
  八股详解下手，再往 [推理](../interview-questions/inference/) 和
  [分布式训练](../interview-questions/distributed-training/) 走。

无论哪条线，[高频面试真题汇总](../interview-questions/高频面试真题汇总.md)
都是你的「考纲」：入门篇里埋的每个伏笔，都在那里以真题频率标注等着你验收。
