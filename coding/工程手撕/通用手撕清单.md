## 题一：LRU Cache

▶ 真题：LRU Cache（哈希表 + 双向链表）——**中高**（通用真题照考，注意是真考，不是"知道就行"）

### 凭什么能被面试官反复考

数据结构经典、代码 50 行以内能写完、且能立刻追下去（线程安全、容量淘汰偶发场景、
Guava/Caffeine/LRU 的实际工程坑）。默写时哨兵节点（dummy head/tail）是最不容易
写错的形式，先背这套。

### 默写版代码

```python
class Node:
    __slots__ = ("k", "v", "prev", "next")
    def __init__(self, k=None, v=None):
        self.k, self.v = k, v
        self.prev = self.next = None

class LRUCache:
    def __init__(self, cap: int):
        self.cap = cap
        self.m = {}                        # k -> Node
        self.head = Node()                 # 哨兵（head<->最旧<->...<->最新<->tail）
        self.tail = Node()
        self.head.next = self.tail
        self.tail.prev = self.head

    # ---- 四个原子操作：remove + append_tail，全部 O(1) ----
    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _append_tail(self, node):
        node.prev = self.tail.prev         # 挂到 tail 前面 = 最新
        node.next = self.tail
        self.tail.prev.next = node
        self.tail.prev = node

    def get(self, k):
        node = self.m.get(k)
        if node is None:
            return -1
        self._remove(node)                 # 用一次就变最新
        self._append_tail(node)
        return node.v

    def put(self, k, v):
        if k in self.m:
            node = self.m[k]
            node.v = v
            self._remove(node)
            self._append_tail(node)
        else:
            if len(self.m) >= self.cap:    # 淘汰最旧 = head.next
                old = self.head.next
                self._remove(old)
                del self.m[old.k]
            node = Node(k, v)
            self._append_tail(node)
            self.m[k] = node
```

### 易错点与追问

- 易错：`_append_tail` 四条指针顺序写错（正确锚点顺序：node.tail 两边先指对，
  再让外部断链）；哨兵省略会在淘汰空表、单节点边界时崩。
- 追问一：**线程安全版？** 答：操作粒度是"查找 + 移动 + 淘汰"的复合操作，只对
  get/put 加一把互斥锁是最简单正确的；追求并发则要分段锁 / 读写锁 + 惰性 purge，
  提到 Caffeine 的 ring buffer + 净页淘汰即可收口。
- 追问二：**为什么不用 OrderedDict？** 真实项目就用它（`move_to_end`+`popitem`），
  但面试默认要写裸结构——能说出这句"生产里我直接 OrderedDict"也是加分。
- 追问三：**淘汰其他策略？** LFU （另加 freq 哈希 + 双链表嵌套，或 heap+timestamp），
  能讲出 LFU 的 O(1) 结构雏形即止。

## 题二：Top-K

▶ 真题：数组中找第 K 大的元素——**中**（通用手撕清单，常被用来问复杂度 trade-off）

### 两种解法对比（这个对比本身才是考点）

| 方法 | 平均时间 | 最坏时间 | 空间 | 适用 |
|---|---|---|---|---|
| 快排 partition（QuickSelect） | **O(n)** | O(n²) | O(1) 原地 | 一次性查询、内存受限 |
| 最大堆 / 最小堆 | O(n log k) | O(n log k) | O(k) | 流式来数据、k 很小 |

**考点**：快速选择平均 O(n)，为什么（每层划分期望砍一半：n + n/2 + n/4 + ... = 2n）。
堆适合"数据流式到达 / k 远小于 n"，但一次性内存里的查询首选 QuickSelect。
能闭嘴默写 QuickSelect，这题就过了。

```python
import random

def find_kth_largest(nums, k):
    """QuickSelect：返回第 k 大（1-based）。平均 O(n)，原地。"""
    def partition(l, r):                     # 取随机 pivot，返回其最终位置
        p = nums[random.randint(l, r)]
        # 三路划分，对大量重复元素更稳
        lt, i, gt = l, l, r
        while i <= gt:
            if nums[i] > p: nums[lt], nums[i] = nums[i], nums[lt]; lt += 1; i += 1
            elif nums[i] < p: nums[gt], nums[i] = nums[i], nums[gt]; gt -= 1
            else: i += 1
        return lt, gt              # [lt..gt] 全是 pivot

    l, r, target = 0, len(nums) - 1, k - 1   # 第 k 大 = 降序下标 k-1
    while True:
        lt, gt = partition(l, r)
        if target < lt:  r = lt - 1
        elif target > gt: l = gt + 1
        else: return nums[target]
```

易错点：随机 pivot（避免有序数组退化为 O(n²)）、三路划分（重复元素多的场景），
"第 k 大"和"前 k 大"问法要分清（前 k 个无序就直接返回 partition 区间）。

## 题三：链表三件套 + DP 中等题选型

▶ 真题：反转链表 / 两数相加 / 排序链表——**中**（通用手撕清单）
▶ 真题：DP 中等题——**中**（应用岗算法题一半是 DP）

### 反转链表（迭代版，默写等级）

```python
def reverse(head):
    prev, cur = None, head
    while cur:
        nxt = cur.next        # 先把 next 记下
        cur.next = prev       # 反转
        prev, cur = cur, nxt  # 整体后移
    return prev
```

### 两数相加（逆序链表 -> 逆序和，逐位进位）

```python
def add_two(l1, l2):
    dummy = cur = Node()
    carry = 0
    while l1 or l2 or carry:
        s = carry + (l1.val if l1 else 0) + (l2.val if l2 else 0)
        carry, digit = divmod(s, 10)
        cur.next = Node(digit)
        cur = cur.next
        l1 = l1.next if l1 else None
        l2 = l2.next if l2 else None
    return dummy.next
```

### 排序链表（归并排序，O(n log n) 时间 O(log n) 栈空间）

```python
def sort_list(head):
    if not head or not head.next:
        return head
    slow, fast = head, head.next          # fast 先行一步，slow 停在中点
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    right = sort_list(slow.next)
    slow.next = None
    left = sort_list(head)
    return merge(left, right)   # 标准两路归并
```

### DP 中等题选型：能用就行，不炫技

应用岗考 DP 不是考你推官方最优解，是考你**识别「这题是 DP」并写出能过的一般解**。
三个够用套路：

1. **识别信号**：问"方案数 / 最值 / 能否达成"，且当前决策只依赖前面状态 → 基本就是 DP。
2. **默写骨架（一维）**：
   ```python
   # 以爬楼梯为例（每步可迈 1 或 2 级，求方案数）
   dp = [0] * (n + 1)
   dp[0] = dp[1] = 1                     # base case
   for i in range(2, n + 1):
       dp[i] = dp[i - 1] + dp[i - 2]     # 转移方程，按题目替换这一行
   print(dp[n])
   ```
3. **常见题目优先级**：爬楼梯（转移入门）→ 最长上升子序列（O(n log n) 二分差分）→
   0/1 背包（二维转一维滚动）→ 编辑距离（面试很爱出）→ 最长公共子序列。
   五题刷熟就够覆盖应用岗 DP 题的 80%。

**别掉坑**：上来就追求二维 DP 的 O(n) 空间优化——先把二维版写对再压；
面试官看的是你"先写对一个能跑的解、再优化"的工程师节奏。
