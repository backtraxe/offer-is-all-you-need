## 面试机制观察（速查）

来自上述各帖与同期社招面经贴（均为二手转述，已脱敏）：

- **字节**：面评连贯——上一面没答好的点下一面会追，答得好的不重复；务必逐轮
  复盘卡点。一面偏简历、二面偏压力（快问快写 + 单题深压）。
- **摩尔线程**：排障实例是硬通货，光讲原理会被反问住；国产卡软件栈（MUSA /
  MCCL）没真踩过坑很难糊弄。
- **大厂 vs 初创**（引自社招系列帖）：大厂 = 算法手撕 + 八股 + 项目三件套；
  初创 = 项目深度 + 实际落地，八股占比低。
- **2026 行情观察**（同帖）：各家均在储备国产算力并真实跑推理业务；
  有大集群经验 + 国产卡实战经验的人市场溢价明显；RL infra / 具身 / 世界模型
  等挂着「训练组」名头的岗位，实际对推理优化经验要求不低——推训一体。
- **手撕行情**（40 天 70+ 场社招样本）：目前多数厂 Infra 岗已不考手撕，字节
  （及个别车企）仍轮轮有；高频题是 LRU、MHA/GQA/MoE/Linear Attention 结构、
  GEMM / online softmax / RMSNorm / Top-K 算子，以及
  「给 config + 硬件参数算 KV Cache / 参数量 / prefill-decode 耗时」的计算题。
