# 低精度预训练专题：从 FP8 到 NVFP4 的 4-bit 训练配方

> **面向**：求职「训练框架 / 大规模预训练」岗的候选人；也适合训练
> Infra 同学补 2026 年低精度浪潮的最新一环。
> **读完获得**：说清「为什么推理早就 4-bit、训练却一直停留在
> BF16/FP8」的三大死结；背下 NVIDIA NVFP4 预训练的五味配方与
> 12B×10T token 实验结论；能讲清每一项技术解决的是哪个数值问题、
> 面试被追问「4-bit 训练为什么难」时有完整对答。
> **口径**：配方与实验数据均来自 NVIDIA 官方博客（2026-10，
> 经公众号「AI圈的9527」转述），性能数字为**官方口径、未经本仓
> 复测**；涉及 Blackwell 硬件描述以官方规格为准。

## 一、直觉先行：推理 4-bit 满地跑，训练为什么不敢？

先看一个不对称现象：

| 场景 | 2026 年主流精度 | 状态 |
|---|---|---|
| **推理** | FP8 日常、NVFP4/MXFP4 上新旗舰 | 已成熟，精度损失可忽略 |
| **后训练（SFT/RL）** | BF16 主干 + FP8 局部 | 半成熟 |
| **预训练（从零训几万亿 token）** | BF16 保底、FP8 勇敢者 | FP8 刚立住，4-bit 是 2026 新前沿 |

为什么训练比推理难整整一代？因为训练多了三样东西：

1. **梯度**：梯度张量的动态范围比前向激活大得多，且逐层、逐 step
   剧烈变化——一套固定的量化网格框不住它；
2. **反向传播**：前向量化一次，反向还要量化一次（梯度对权重、
   对激活各一次），前后向量化方式**不对齐**就是注入系统性失真；
3. **误差累积**：推理一张量量化一次就完了，训练是**几百万步的
   迭代**——每步一点点舍入偏差，10 万亿 token 积累下来足以让
   loss 曲线飘走或发散。

一句话：**推理量化是「一次性压缩」，训练量化是「在噪声里保持
几百万步的动力系统稳定」**。这就是为什么基座模型长期靠 BF16
保底，FP8 预训练（DSv3 等）刚被验证，而 NVFP4 预训练直到
Blackwell 落地才被 NVIDIA 正面攻破。

## 二、硬件底座：为什么 Blackwell 是转折点

低精度预训练的前提是**硬件原生支持**——软件模拟的 FP4 只会更慢。

| 平台 | FP4 支持 | 官方口径的关键数字 |
|---|---|---|
| Hopper（H100/H200） | 无原生 FP4 Tensor Core | FP8 是上限 |
| **Blackwell（GB200/GB300）** | **首个原生支持 FP4 的架构** | GB300 实测 GEMM 性能**相对 Hopper 约 7 倍**（官方口径） |

为什么 GEMM 数字重要？现代 LLM 的算力大头就是线性层矩阵乘——
FP4 让前向 GEMM、反向两个 GEMM（权重梯度、激活梯度）全程加速，
**time-to-train 整条缩短**。换句话说：没有原生 FP4 Tensor Core
之前，「4-bit 预训练」就算数值上可行，工程上也是亏本买卖；
Blackwell 把它从「有意思」变成「有账本」。

再补一层系统视角：精度砍半不只是算得快——**内存需求降、算术
吞吐升、通信量减**（all-reduce/all-gather 的字节数随位宽缩），
同样的 AI 工厂能推更多 token。官方那句话可以直接背：
**「功耗预算固定、GPU 时间稀缺时，每个比特都要算账——精度不再
是后端细节，它是 AI 工厂的战略资产。」**

## 三、NVFP4 预训练五味配方（核心背诵区）

NVIDIA 的 NVFP4 预训练配方针对的就是第一节的三大死结。五项
技术各有分工，面试要能一个一个报出来：

### 3.1 微块缩放（Microscaling）：块从 32 缩到 16

- **问题**：量化块内只要有一个离群值，整个块的 scale 就被它
  拉大，其余值被压进粗网格——误差由块内最极端的元素决定。
- **做法**：NVFP4 规定**每 16 个 4-bit 元素共享一个 scale**
  （对比 MXFP4 是 32 个）。块越小，离群值的影响半径越小，
  scale 越贴身。
- **代价**：scale 存储开销翻倍（每 16 元素一个）——用精度换
  字节，NVIDIA 认为值。

### 3.2 高精度 scale 编码：E4M3 换掉 E8M0

- **问题**：MXFP4 的 scale 是 **E8M0**——没有尾数位，**只能表示
  2 的幂**。真实张量的最优 scale 几乎从不恰好落在 2 的幂上，
  scale 自身就带着粗糙的舍入误差。
- **做法**：NVFP4 的 scale 改用 **E4M3**（4 位指数 + 3 位尾数），
  缩放粒度细了一档，块内有限的量化桶被利用得更充分。
- **记忆点**：「**块大小决定离群半径，scale 尾数决定缩放细度**」
  ——3.1 和 3.2 是正交的两刀。

### 3.3 Hadamard 变换：先把张量「揉匀」再量化

- **问题**：预训练的梯度和激活常带大离群值（outlier），窄精度
  量化最怕这个——少数离群点吃掉大部分量化动态范围。
- **做法**：对 GEMM 输入施加 **Hadamard 变换**（正交变换，能量
  重排），把分布从高瘦的尖峰揉成更接近高斯的形状，**离群值被
  数学地抹平**，张量变好表示。
- **工程特性**：变换对模型架构**透明**——前向和反向的线性层
  两侧都能插入，不改网络结构、不改语义（正交变换保内积）。
- **串联**：思想与推理侧的 SmoothQuant 同源（都是「把难量化的
  分布先整形成好量化的分布」），只是 SmoothQuant 做逐通道均衡、
  Hadamard 做全局旋转。

### 3.4 2D 块量化：前后向量化方式必须对齐

- **问题**：第一节死结之二——前向按一种方式量化、反向按另一种，
  梯度信号就被系统性扭曲，几百万步累积下来收敛行为变差。
- **做法**：**选择性的 2D 块量化**——对 GEMM 的两个操作数沿
  两个维度分别组织量化块，保证训练全程（前向/反向、权重/激活）
  张量表示一致。
- **效果**：信号失真小、收敛行为接近高精度训练、鲁棒性强——
  在 4-bit 这种「没有容错余量」的位宽下尤其关键。

### 3.5 随机舍入（Stochastic Rounding）：消灭系统性偏差

- **问题**：确定性舍入永远「就近」，对梯度这种大量小数值张量是
  **有偏估计**——每步都往同一个方向偏一点点，偏差在百万步上
  单调累积。
- **做法**：随机舍入按「数值到两个相邻可表示值的距离比例」
  随机上舍或下舍——单步有噪声、**期望无偏**，噪声在多步平均中
  相互抵消，梯度流不被截断。
- **一句话**：**「确定性舍入是温水煮青蛙的偏差，随机舍入是会
  被大数定律赦免的噪声。」** 训练中后期对最终精度影响显著。

### 配方分工速记表

| 技术 | 对准的死结 | 一句话 |
|---|---|---|
| 微块缩放（16 元/块） | 离群值影响半径 | 块越小，离群传染越少 |
| E4M3 scale | scale 自身精度 | scale 带尾数，缩放不粗糙 |
| Hadamard 变换 | 动态范围/离群值 | 先揉匀分布再量化 |
| 2D 块量化 | 前后向对齐 | 全程表示一致，信号不失真 |
| 随机舍入 | 梯度舍入偏差累积 | 用无偏噪声换掉有偏舍入 |

## 四、实验：12B × 10 万亿 token，从零训起

配方的成色要看大规模实证。NVIDIA 的验证设定（官方口径）：

| 维度 | 设定 |
|---|---|
| 模型 | **12B 参数 Hybrid Mamba-Transformer** |
| 数据 | **10 万亿 token**，分阶段数据混合：70% 处切第二阶段配比，90% 处切第三阶段 |
| 基线 | 同模型同数据的 **FP8 预训练**（既往研究已验证 FP8 接近 16-bit 精度） |
| 方式 | NVFP4 **从零训练（from scratch）**，非 QAT 微调 |

结果三条：

1. **收敛稳定性**：NVFP4 全程收敛稳定，没有出现超低精度训练
   常见的 loss 抖动与发散（**官方口径**）；
2. **验证 loss**：从 0 到 10 万亿 token，NVFP4 与 FP8 基线的
   **验证 loss 曲线全程贴合**（官方放出的曲线图）；
3. **下游任务**：六个智能域——MMLU Pro、MMLU、代码、数学、
   常识理解、多语言——NVFP4 与 FP8 **基本持平**（官方口径）。

含金量解读：这不是「训后量化一个现成模型」，而是**从 random
init 开始的完整预训练动力学**——梯度、优化器状态、数据配比
切换（70%/90% 两个相位点）全在 4-bit 下经受考验。10 万亿 token
也是当下旗舰模型的真实数据量级，不是玩具规模。

## 六、把 NVFP4 放回自己脑中的知识地图

- **格式定义**（微块 16、E4M3 scale、E2M1 主体）在推理侧已讲透，
  见「串联阅读」的量化与压缩——**本文新增的只是训练侧配方**；
- **与 FP8 预训练的关系**：DSv3 验证了 FP8 从零预训练可行
  （见训练光速手算实战专题的 FP8 光速换算），NVFP4 是同一方向
  再砍一半位宽；两者之间隔着 Blackwell 原生 FP4 这个硬件前提；
- **与 MXFP8/MXFP4 训练路径的关系**：Megatron 系在推 MXFP8 训练，
  开放规范阵营走 MXFP4（见训练框架 2026 新进展）——NVFP4 是
  NVIDIA 自家格式 + 自家硬件的垂直整合打法；
- **训练推一体的视角**：训练用 NVFP4、推理也 NVFP4，意味着
  **checkpoint 不再需要反量化中转**，训推格式同源——与 RL 系统
  「训推一体」专题里的格式对齐问题直接相关。

## 七、▶ 面试题

**Q1【高】4-bit 量化做预训练，难在哪？推理不是早就 4-bit 了吗？**
答：三个层次。① 梯度动态范围比前向激活大且逐 step 剧变，固定
量化网格框不住；② 训练是前向+反向双重量化，前后向量化方式不
对齐就注入系统性失真；③ 最要命的是迭代累积——推理量化一次，
训练要几百万步，每步一点有偏舍入，10 万亿 token 攒下来 loss 就
飘了。所以训练量化不是压缩问题，是动力系统稳定性问题。

**Q2【高】NVFP4 预训练的五项技术分别解决什么问题？**
答：微块缩放（16 元素共享 scale）缩小离群值的影响半径；E4M3
scale（带尾数）提高缩放精度，对比 MXFP4 的 E8M0 只能表示 2 的
幂；Hadamard 变换把激活/梯度分布揉成类高斯，数学抹平离群值，且
正交变换对架构透明；2D 块量化保证前向反向表示一致，梯度信号不
失真；随机舍入把有偏的确定性舍入换成期望无偏的噪声，靠大数定律
在百万步上抵消。前两个管「表示精度」，中间两个管「分布与一致性」，
最后一个管「迭代偏差」。这个三分法比逐条背更显体系感。

**Q3【高】为什么 Blackwell 之前没人做成 4-bit 预训练？**
答：硬件是必要条件。没有原生 FP4 Tensor Core，软件模拟 FP4 只有
精度开销没有速度收益——4-bit 的账算不平。Blackwell（GB200/GB300）
是首个原生支持 FP4 的架构，官方口径 GB300 GEMM 相对 Hopper 约
7 倍，而这个 7 倍同时作用于前向和反向的全部线性层，time-to-train
整体缩短。低精度研究的节奏基本是跟着硬件代际走的：Volta→FP16、
Hopper→FP8、Blackwell→FP4。

**Q4【中】Hadamard 变换为什么能抹平离群值？对模型有影响吗？**
答：Hadamard 是正交变换，作用是把张量元素的能量重新混合——原本
集中在少数维度上的离群峰值被分摊到整个向量上，分布更接近高斯。
因为正交变换保内积，插在 GEMM 两侧不改变数学语义（乘上逆变换
就还原），所以对模型架构透明，前向反向的线性层都能用。思想与
推理侧 SmoothQuant 同源：先把「难量化的分布」整形成「好量化的
分布」，再量化。

**Q5【中】随机舍入为什么比「就近舍入」好？不会引入噪声吗？**
答：会引入噪声，但噪声和偏差不是一回事。确定性舍入对小梯度是有
偏的——每步都同向偏一点，几百万步单调累积，温水煮青蛙。随机
舍入按距离比例随机上下舍，单步是噪声、期望无偏，百万步上噪声
相互抵消（大数定律），梯度流的净通量被保住。训练中后期对最终
精度有实质影响。这也回答了 Q1 里的死结三：迭代怕的是「偏」，
不是「噪」。

**Q6【中】NVIDIA 怎么验证这套配方？实验设计的看点是什么？**
答：12B Hybrid Mamba-Transformer、10 万亿 token、从零训练；基线
是同模型 FP8（已被验证接近 16-bit）；验证 loss 全程贴合、下游
六个域（MMLU Pro、MMLU、代码、数学、常识、多语言）基本持平——
均为官方口径。设计看点：① 从零训而非 QAT，考验完整训练动力
学；② 10T 是旗舰级真实数据量；③ 数据配比在 70%/90% 处切换
相位，证明配方兼容真实 recipe 的多阶段调度，不是单一分布的
理想环境。

**Q7【低】NVFP4 训练和 MXFP8（Megatron 路线）是什么关系？**
答：同一场代际竞赛的两条路线。MXFP8 是 OCP 开放规范，块 32 元素、
E8M0 scale，AMD/微软/开源阵营在推，Megatron 已有 MXFP8 训练路径；
NVFP4 是 NVIDIA 自家格式（块 16、E4M3 scale）+ 自家 Blackwell 硬件
的垂直整合。位宽上 NVFP4 更激进（4 vs 8），封闭换极限；MXFP8 更
保守但生态开放。面试别站队，说清 trade-off 即可。

**Q8【低】如果 NVFP4 预训练成立，对下游环节有什么连锁影响？**
答：三个连锁。① checkpoint 格式：训推同源（训练 NVFP4、推理
NVFP4），不再需要反量化中转，RL 训推一体的格式对齐问题简化；
② 成本模型：预训练 token 吞吐预期上一个台阶，同等 AI 工厂预算
能训更大模型或做更多实验；③ 精度话语权：基座本身就在 4-bit
动力学下收敛过，后训练/推理再用 4-bit 的兼容性论证会更顺——
「出生即量化」的模型对量化扰动天然更耐受（这一点官方未直接
声明，属合理外推，面试要标注）。
