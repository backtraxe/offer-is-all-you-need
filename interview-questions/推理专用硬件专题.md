## 〇、核心结论五条

1. **赛道根本洗牌**：2025-12 NVIDIA 以约 200 亿美元（CNBC/Reuters
   2025-12-24）拿下 Groq 核心资产与技术授权，2026-08 产品化为 NVIDIA
   Groq 3 LPX 整合进 Vera Rubin 平台——**挑战者被 GPU 巨头吸收头部玩家，
   SRAM-only decode 成为 GPU 阵营标准补充**。交易本身存在三个互斥口径，
   见第一节。
2. **Cerebras 是唯一跑通 wafer-scale 商业闭环的玩家**：**2026-05-14 Nasdaq
   IPO（CBRS），发行价 $185、募资 55.5 亿美元、开盘 $350、估值约 950 亿**
   （Reuters/CNBC 2026-05），并拿下 OpenAI 百亿美元订单（CNBC 2026-01）。
   但上市后股价曾跌破发行价——**市场认可快、质疑贵与集中度**。
3. **架构账本质是带宽账**：decode 单用户吞吐 **上限 ≈ 有效显存带宽 ÷ 每
   token 需读权重字节数**。GPU HBM 约 3–8TB/s；Groq 片上 SRAM 约 80TB/s
   （官方宣称）；Cerebras WSE-3 片上 **21 PB/s**（ServeTheHome 2026-08 核实
   规格表）。专用卡快在带宽与每 token 读量的比值高一到三个数量级。
4. **代价是容量与通用性**：SRAM 每 GB 硅成本比 HBM 高一到两个数量级——
   Groq 单芯片只有 **230MB SRAM**（ISCA 2020），跑 70B 需数百颗组网；
   Cerebras 用整片 300mm 晶圆换 **44GB SRAM**（WSE-3, STH 2026-08）。
   两者都几乎不能做训练，prefill 也没有优势。
5. **2026 真实定位**：PD 分离后适合做 **decode / 高交互档（interactivity
   tier）**；「GPU 做 prefill、专用芯片做 decode」被 NVIDIA LPX 文档与
   SambaNova×Intel 蓝图双双收成行业配方。主战场是主权 AI、低延迟实时、
   高单价 premium serving；量级上市占仍只是 **GPU 的个位数百分比补充**
   （定性口径）。

## 二、Groq（LPU/TSP）：静态调度换带宽利用率

### 2.1 架构三件套

Groq 2016 年由 TPU 作者 Jonathan Ross 创立，核心是**编译器静态调度 +
确定性运行**：

1. **编译期逐时钟周期排好一切**——所有数据搬运与计算在编译期就确定了
   每个周期做什么，运行时不再做任何动态决策；
2. **去掉动态硬件**——没有 cache、没有分支预测、没有仲裁器（ISCA 2020），
   省下的面积与功耗全给了计算与片上存储；
3. **权重全驻留 SRAM**——单芯片 **230MB 片上 SRAM、无 HBM**，约 375W/芯片，
   14nm、25×29mm、900MHz（ISCA 2020，Wikipedia 引用链）。

### 2.2 代价与放大器

- **容量硬伤**：230MB 装不下任何像样的大模型，70B 需数百颗芯片组网——
  这是 SRAM-only 路线的结构性代价。
- **确定性是双刃剑**：好处是 TP 通信开销极小、P99 尾延迟平；坏处是对
  模型架构变化（尤其 MoE 稀疏路由）适应性差——面试被问「MoE 对专用卡
  利好还是利空」时这一点是半边答案。
- **云上历史速度数字的纪律**：Groq 云上 Llama 3.3 70B、gpt-oss-120B 等
  模型的 tok/s 历史数字，本文按**官方宣称 / 当时媒体实测量级（数百
  tok/s 区间）**处理，不给精确小数（依据见文末未核实说明）。

### 2.3 NVIDIA Groq 3 LPX：收编后的产品形态

- **单机架 256 颗 LP30、机架共 128GB SRAM（约 512MB/颗）、每芯片 96 路
  112Gbps C2C 互联**（NVIDIA 官方博客 2026-08）。
- AA 第三方实测：**Gemma 4 31B @100K 上下文 3,431 tok/s**（10K 上下文下
  3,382，AA 2026-08）——长上下文下速度基本不塌，是它主打 agentic 多轮
  场景的底气。

## 三、Cerebras：整片晶圆换 44GB，唯一跑通的商业闭环

### 3.1 WSE-3 规格锚

整片 300mm 晶圆做成一颗芯片，靠冗余核与绕障布线解决良率。**TSMC 5nm、
4 万亿晶体管、900K 核、44GB SRAM、21 PB/s 片上带宽、125 PFLOPS FP16

STH）；整机功耗 **约 54kW（媒体推算，非官方数字）**。单节点价格传
**约 $3M（媒体推算）**。

## 六、架构账推导：带宽 ÷ 字节数

### 6.1 公式

**decode 单用户上限 = 有效带宽 ÷ 权重字节数**。推导：decode 每步生成一个
token，需要完整读一遍全部权重；batch=1 时 KV 读取相对整遍权重可忽略。
所以单用户 tok/s 上限 ≈ 有效内存带宽 ÷ 权重总字节数。

### 6.2 各型号代入

| 平台 | 权重字节数（70B BF16） | 有效带宽 | 理论上限口算 |
|---|---|---|---|
| H100（HBM3 3.35TB/s） | 140GB | ~3.35TB/s | 140÷3.35 ≈ **24 tok/s**，MFU 打七折后 15–20 |
| 同模型 INT8 | 70GB | 同上 | 带宽不变读量减半 → 直接翻倍，**量化对 decode 是带宽直接换速度** |
| Groq LPU 组网 | 140GB（~600 颗拼） | 聚合 ~48TB/s 级 | 数百 tok/s；确定性调度让大 TP 通信几乎不浪费 |
| Cerebras WSE-3 | 44GB 装不下，多晶圆流水线 | 片上 21PB/s | 数千 tok/s（实测见 3.2） |
| NVIDIA LPX（256 颗/128GB） | 31B 级机型实测 | 片上 SRAM | **3,431 tok/s**（AA 2026-08） |

**为什么快**：不是算力大——Groq v1 的算力反而小——而是**带宽与每 token
读量的比值大一到三个数量级**，加上小 batch 下 TP 通信被静态调度压平。

### 6.3 为什么做不了训练：三条

1. **FLOPS/$ 不占优**：训练吞吐看 FLOPS × 大 batch 利用率，SRAM 卡在
   FLOPS 性价比上没有任何优势；
2. **装不下训练状态**：训练状态 ≈ 12–16× 参数字节（权重+梯度+优化器），
   片上容量差两个数量级；外挂 HBM/DDR 等于把带宽优势亲手还回去；
3. **静态调度忌动态图**：训练需要频繁动态控制流（重分片、gradient
   checkpointing、variable length），静态编译换图要整体重编译，慢。

Cerebras 能做训练，但靠 MemoryX/SwarmX 外挂权重流，处于生态边缘。

### 6.4 prefill 同样没有优势

prefill 是 compute-bound——大 GEMM 打满算力即可，HBM 足够把算力喂饱。
因此 **2026 年全行业收敛到同一配方：GPU prefill + SRAM/RDU decode**
（NVIDIA LPX 文档、SambaNova×Intel 蓝图白纸黑字）。

### 6.5 小模型与量化的双面性

- **速度轴**：模型变小后同样能整装进 SRAM，专用卡的相对优势**放大**；
- **TCO 轴**：模型小，GPU 单卡就能做很大的 batch，tokens/$ 追平，优势
  **缩小**。

结论：**速度档永久领先，性价比档只在用户愿为速度付溢价时成立**——
「这类卡赢速度档不赢吞吐档」。

### 6.6 GPU 的护城河与专用卡的窗口

GPU 护城河三条：**CUDA 生态**（任何模型当天能跑）、**训推兼用**（同集群
双用途、利用率高）、**供应链与机架集成成熟度**。专用卡的窗口由两个
2024–2026 的事实顶开：**模型架构趋于稳定 + 推理占比爆发**——架构稳定
才敢固化硬件，推理够大才摊得平专用产线。

## 七、市场与选型（2026 口径）

### 7.1 四个真实场景

1. **高交互 premium 档**——OpenAI/Anthropic 均推出 Fast/Priority 档、按
   2–2.5× 定价（Positron 官网引述 2026-09），**token 速度本身成了可贩卖
   的商品**，这是 SRAM 卡的商业根基；
2. **agentic 多轮长上下文**——LPX 主打 100K+ 上下文速度不塌；
3. **sovereign AI**——沙特 × Groq（$1.5B 承诺）、UAE × Cerebras/G42；
4. **云厂商异构 decode**——AWS × Cerebras、Nebius 首发 LPX、OVHcloud ×
   SambaNova。

### 7.2 tokens/$ 账本：别背厂商数字

AA 数据显示：Cerebras/Groq 按 API 定价与 GPU 云**同价甚至略贵**——
**赢的是 tok/s 上限与长尾延迟稳定性**（确定性调度把 P99 压平），token/$
不一定赢。市场上 6×、2.4× 这一档互黑数字（各家对 GPU 或彼此宣称的成本
优势）**一律只能写厂商主张**，本文不采信为事实。

### 7.3 选型公式

- 愿为速度付钱 / 延迟 SLO 严格（实时语音、交易、pair-programming）→
  专用卡 decode 档；
- 追吞吐与通用性、要训练、模型迭代快 → GPU 全栈；
- 落地形态大概率是**异构混部**：GPU prefill + 专用卡 decode + CPU 做
  agentic 工具计算。

## 八、▶ 面试题十条

1. ★★★★★ **decode 为什么 memory-bound？70B 单用户 tok/s 上限怎么推？**
   ——decode 每步完整读一遍权重，batch=1 时 KV 可忽略 → 上限 ≈ 带宽 ÷
   权重字节数。140GB ÷ 3.35TB/s ≈ 24 tok/s 理论值，MFU 七折后 15–20。
2. ★★★★★ **Groq 为什么 tok/s 高但 TCO 不一定赢？**——四连：单芯片
   230MB → 跑 70B 要数百颗组网；量化 INT8 才能全速；AA 口径 API 定价不
   比 GPU 云便宜；**赢速度档不赢吞吐档**。
3. ★★★★ **SRAM 为什么比 HBM 快？代价是什么？**——片上距离近、无 PHY
   开销、随机访问友好；代价是同硅面积下 GB 数少两个数量级，所以只能走
   wafer-scale（Cerebras）或多芯片组网（Groq）两条路。
4. ★★★★ **为什么这类芯片做不了训练？**——§6.3 三条：FLOPS/$ 无优势；
   训练状态 12–16× 参数字节装不下、外挂等于还回带宽；静态调度不适合
   动态图。
5. ★★★★ **PD 拆开后专用卡放哪端？**——2026 标准答案：**GPU prefill /
   LPU·RDU decode**，NVIDIA LPX 与 SambaNova×Intel 蓝图双实证。
6. ★★★ **模型变小，专用卡优势放大还是缩小？**——双轴答：速度轴放大
   （同样装得下、带宽优势不变），TCO 轴缩小（GPU 大 batch 把 tokens/$
   追平）。
7. ★★★ **MoE 对专用卡利好还是利空？**——利空为主：激活参数少 → 每
   token 权重读取少，GPU 也能跑快，带宽差优势被压缩；且稀疏路由增加
   调度复杂度，对静态调度不友好（Etched 转向 HBM/SRAM 混合的公开理由）。
8. ★★ **KV cache 放哪？**——SRAM 只放权重，KV 靠片外 DRAM/LPDDR
   （NVIDIA LPX 与 MatX 都是公开设计）。
9. ★★ **为什么不能全用 SRAM 替代 HBM？**——良率、散热、容量逐个拆；
   d-Matrix Raptor（3D DRAM 键合）、3D 堆叠 SRAM、存内计算是正在收敛
   的方向。
10. ★★★ **怎么看 NVIDIA 收 Groq？专用芯片还有独立窗口吗？**——**赛道
    没死，是被吸收为 GPU 生态的标准异构件**；独立窗口 = sovereign AI +
    premium 速度档 + 主权客户的第二供应链需求。

## 九、口径与未核实说明

- **Groq 云上历史 tok/s**：按「官方宣称 / 当时媒体实测量级」书写，不给
  精确小数；AA 实际数字经 Cerebras 博客引用，**引用方为竞品**，交叉引用
  时必须标注利益相关。

  口径」。
- **d-Matrix 带宽/能效数字**：标「官方宣称、未独立复核」。
- **Etched Sohu 原始宣称**：标「官方宣称」并注明**原始 blog 已下线**。

  非官方数字。
