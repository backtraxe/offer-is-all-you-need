# Scaling Law 与三代范式迁移：预训练 → 后训练 → 推理时计算

> 本篇面向想把「为什么模型越训越大、为什么 2025 年风口转到强化学习
> 和长思考」讲成一条线的读者。Scaling Law 是全仓少数真正能
> **串联所有模块**的理论骨架：预训练与数据工程、MoE、RLHF/RLVR、
> 推理引擎优化，全都是它在不同阶段的投影。读完你会获得：幂律公式
> 与 Chinchilla 配比的"怎么算+为什么"、三代范式的迁移逻辑、
> 数据墙问题，以及面试高频推导题。
> 时效口径：2026-10 核实。

## 一、Scaling Law 是什么：一句话 + 一个公式

**一句话**：在架构与数据分布不变的前提下，模型 loss 沿着
参数量 N、数据量 D、算力 C 走**平滑幂律**（power law）——
log-log 图上是一条直线，外推靠谱。

Chinchilla 形式化（DeepMind, 2022）：

```
L(N, D) = E + A/N^α + B/D^β        E≈1.69, α≈0.34, β≈0.28
```

拆开读三项：**E 是数据生成本身的不可约熵**（天花板）；
**A/N^α 是模型太小欠拟合的项**；**B/D^β 是数据太少没学够的项**。
固定算力 C≈6ND 去最小化 L，就得到计算最优配比：

```
compute-optimal： D* ≈ 20 × N     （每参数约 20 个 token）
```

**为什么是幂律而不是别的形状**？直觉版：自然数据的"难样本"呈
长尾分布，模型容量每翻一档就把长尾削掉一截，收益随规模**递减
但永不归零**——loss 对规模的对数导数恒定就是幂律。工程上它值钱的
地方在于**可以花小钱外推大钱**：用小模型扫出 scaling 曲线，预测
大卡时该配的 N/D，Muon 等新优化器也要在这一步重新标定系数
（见 [Muon 与新优化器](./muon与优化器.md)）。

## 二、三代范式：同一条定律的三次重新理解

### 第一代：预训练 Scaling（Kaplan 2020 → Chinchilla 2022）

OpenAI Kaplan 论文（2020）先给出幂律，但结论是"**优先堆参数**"
——GPT-3 175B 只吃了 300B token，按后来的标准是严重欠喂的。
DeepMind Chinchilla（2022）用 400 次小实验翻案：同一预算下
70B × 1.4T token 打平 280B × 300B（Gopher），**问题不在模型多大，
在于配比**。之后 LLaMA 系干脆**过训练**：7B 喂 1T token
（D/N≈140），因为推理是终身成本、训练是一次成本——小模型喂到饱，
部署总账更省。这是"为什么 LLaMA 故意欠配比"的 why。

### 第二代：数据墙与重心迁移（2023-2024）

按 D≈20N 配比外推，高质量人类文本在 **10-30T token 量级见底**
（Epoch AI 2024 估算），合成数据、私有数据、多模态数据变成刚需
（见 [数据工程专题](./数据工程专题.md)）。"预训练 scaling 撞墙了
吗"成为 2024 年底 Ilya 在 NeurIPS 抛出的名场面："我们所知的
预训练将会终结"——意思不是幂律失效，是**单变量（D）便宜粮吃完**，
要继续降 loss 得换更贵的变量。

### 第三代：后训练与推理时计算（2024-）

换的方向有两个，都是"**把算力从训练时挪到别处**"：

- **后训练 scaling**：o1（2024-09）、DeepSeek-R1（2025-01）证明
  在可验证任务上用 RL 继续训（RLVR/GRPO，见
  [RLHF 与对齐](./rlhf与对齐.md)），能力随 RL 训练算力走出
  **自己的 scaling 曲线**——低置信度率先出现"自我反思/aha moment"
  等涌现行为。预算口径从"预训练 FLOPs"扩成"pretrain + RL 两个池"。
- **推理时 scaling（test-time compute）**：不训也行——让模型
  **多想**。同一模型给更长的思考链（CoT）、更多采样（best-of-N）、
  搜索（MCTS），准确率随"思考 token 数"走幂律。代价转移到推理
  侧（prefill/decode 变重），这正是推理引擎模块整章存在的原因
  （见 [vLLM 与推理加速核心](../inference/vllm与推理加速核心.md)）。

一句话收拢三代：**第一代堆参数、第二代堆数据、第三代堆
"思考"——每一次都是上一个便宜变量见顶后，换下一个还没见顶的
变量**。MoE 是其中"堆参数但只激活一小部分"的折中（见
[MoE 架构](../llm基础/moe架构.md)）。

## 三、数字锚点（面试报得出才稳）

| 数字 | 含义 | 出处 |
|---|---|---|
| D ≈ 20N | Chinchilla 计算最优配比 | DeepMind 2022 |
| 70B × 1.4T ≈ 280B × 300B | 同预算小模型+多数据打平巨型欠喂模型 | Chinchilla vs Gopher |
| 7B × 1T（D/N≈140） | 推理优先时的故意过训练 | LLaMA-1（2023） |
| ≈557 万美元 / 278.8 万 H800·h | DeepSeek-V3 一次正式训练账面成本（后训练另计） | DeepSeek-V3 论文 |
| 自然文本 ~10-30T 见底 | 数据墙的量级估算 | Epoch AI（2024） |
| RL 预算独立成池 | 后训练 scaling 曲线首次公开化 | o1 / R1（2024-25） |

记法："**20 倍配比、一种过训练、两堵墙、三个池**"——数据墙
与演示墙（能力见顶的担忧）是两堵；算力池从预训练一个变成
预训练/后训练/推理时三个。

## 四、与其他模块的接口（why 都要从这出发）

- **MoE**：_scaling law 里的 N 换成"等效稠密参数"后幂律照样成立
  ——稀疏就是用通信成本换"更大的名义 N"。_
- **量化/推理**：LLaMA 式过训练证明推理成本终身上杠杆，倒逼
  [量化与压缩](../inference/量化与压缩.md)、
  [PD 分离](../inference/推理服务slo与运营.md) 成为主战场。
- **RLVR**：RL 的 scaling 系数（α_rl）比预训练小得多但初值低——
  底座越强 RL 收益越大，所以"先重预训练后重 RL"的顺序没错。
- **数据工程**：数据墙使"数据质量/配比/合成"从配菜变主菜，
  FineWeb、DCLM 这些开放配方成了新一代可复现阵地。

## 五、面试问答

**Q：Scaling law 讲一讲。**
幂律：L = E + A/N^α + B/D^β，log-log 下线性地外推。
工程用：小模型扫曲线定系数 → 预测大模型的最优 N/D 配比。
Chinchilla 的结论是 D≈20N，GPT-3 那代欠喂，LLaMA 那代反着来
过训练——因为训练一次、推理千万次，小模型喂饱部署总账最省。

**Q：为什么 2024 年后大家转向 RL / test-time compute？**
不是预训练幂律失效，是便宜变量见顶：D≈20N 的配比外推撞上自然
文本 10-30T 的数据墙，继续纯堆 D 边际成本陡增。RLVR 给出新的
scaling 曲线（RL 算力→可验证任务能力），推理时计算给出"不训练
也能换能力"的通道。三代范式本质是换还没见顶的变量。

**Q：你怎么评估"这个模型该配多少数据"？**
看目标是训练成本最优还是全生命周期最优：前者 D≈20N；
后者（推理量大）故意过训练，D/N 拉到 50-100+，用推理省的
算力抵训练多花的。加一个现实约束：好数据不够时，加数据比加
参数便宜——这就是数据工程的立项理由。

**Q：MoE 怎么放进 scaling law？**
把 N 换成等效稠密参数（按激活参数的某个放大系数折算）后按同一
幂律读；等效系数由质量外推测出。结论：同算力下 MoE 能走到
更大的名义 N 与更低的 loss，代价是训练/推理的通信与工程复杂度
（EP、all-to-all、EPLB）。

**深挖可能**：Chinchilla 系数会被新优化器/新架构改写吗？
→ 会，Muon、线性注意力等都要重扫系数，scaling 是"给定配方下"
的定律，配方换代就要重新标定——但仍可外推，这就是它不死的原因。
