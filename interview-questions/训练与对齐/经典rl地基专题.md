# 经典 RL 地基专题：从 MDP 到 PPO，一路映射到 RLHF

> **面向**：已懂 LLM 基本盘（token、logprob、采样）但 RL 零基础、准备
> 「RLHF 深挖」追问线的读者。本仓的 [rlhf与对齐](./rlhf与对齐.md) 从
> PPO 直接起步，本篇补的是它脚下那层经典
> 地基：MDP → 贝尔曼方程 → DP/MC/TD → on/off-policy → 策略梯度 →
> Actor-Critic → PPO，每讲一个经典概念，当场翻译回 LLM/RLHF 场景。
>
> **读完获得**：① 五张映射表——MDP 五元组、GAE 是 TD 家族的旋钮、
> PPO 的 clip 是对 off-policy 偏差的妥协、组内均值是无 critic 的
> advantage、critic 就是价值模型；② 一道能手算验算的贝尔曼计算题模板；
> ③ 9 道面试题的参考答法。
>

## 一、为什么 LLM 面试会问经典 RL

很多人背 RLHF 是从「RM 打分、PPO 更新、KL 别跑太远」背起的，但面试官
往下追半句，问题就全落在经典地基上。四个面经里的真实追问：

1. **追问一：PPO 为什么要 clip？** 只答「防止步子太大」算半对。完整答案是：
   rollout 很贵，一个 batch 想复用几步，就引入了旧策略采样、新策略更新的
   偏差——clip 是把这个偏差按住的工程妥协。要讲清楚它，你得先有
   on/off-policy 和重要性采样的地基（第五节）。
2. **追问二：GAE 是什么、λ 怎么调？** 答案不在 GAE 论文里，在 TD 家族的
   偏差-方差谱系上：λ 是一个旋钮，一头连着 MC（低偏差高方差）、一头
   连着一步 TD（高偏差低方差）。不懂 MC vs TD，λ 你就是死背的（第四节）。
3. **追问三：贝尔曼方程写出来，这个两状态 MDP 你手算一下 V。** 小而硬的
   计算题，白板上错一个符号就挂，文末给了可复算的模板（第三节）。
4. **追问四：PPO/GRPO 到底算 on-policy 还是 off-policy？** 这是一道没有
   一句话答案的题，答法要画「有限复用」的光谱（第五节，Q5 给了答法）。

所以本篇的主线只有一句话：**记住，LLM 是一个 action 空间巨大、
reward 稀疏、但 transition 完全确定性的 MDP。** 后面每一节都是它
的一个侧面——
先把经典概念讲透，再把它折回这个特殊的 MDP 上。

## 二、MDP 五元组：把一次生成翻译成强化学习

马尔可夫决策过程是一个五元组 (S, A, P, R, γ)。先给通用定义，再给
LLM 翻译——映射表是面试第一问的标准答法：

| 元素 | 通用含义 | LLM/RLHF 翻译 |
|---|---|---|
| S 状态 | 环境的完整描述 | prompt + 已生成的 token 前缀，即 s_t = (x, y_<t) |
| A 动作 | 可选决策集合 | 从词表里挑下一个 token，动作空间大小 = 词表大小 |
| P 转移 | P(s′, r | s, a)，环境的动力学 | **确定性拼接**：s_{t+1} = s_t 后接 a_t，无随机 |
| R 奖励 | 环境给的标量信号 | RM 打分或规则验证（答案对错、代码过不过单测） |
| γ 折扣 | 未来奖励的折现率 | LLM 场景常用 1（生成是有限步、终点 reward 不折现） |

一条 episode 就是完成一次完整生成：从空前缀（状态 s_0 = x）逐 token
走到 EOS，拿到一个终止奖励，轨迹 τ = (s_0, a_0, s_1, a_1, …, s_T)。

这张映射表要背，但更要讲出 LLM 场景的**两个特殊性**，这才是追问点：

- **Transition 是确定性的。** 给定前缀，环境只负责把 token 拼接上去，
  没有物理噪声、没有对手。这意味着 LLM 的「环境」平凡到不需要学——
  所有的随机性都在策略 π（采样温度）和 reward 端。这也是 RLHF 可以
  直接用策略梯度硬冲、不需要 model-based 学动力学的缘故。
- **Reward 是稀疏的。** 多数 RLHF/RLVR 设置下，中间 token 全部没分，
  只有走完整条轨迹才拿到一个标量。稀疏 reward 直接把 credit
  assignment（到底是哪一步 token 立了功、闯了祸）变成核心难题——
  第四节的 TD 家族和第七节的 advantage 就是为这个问题服务的，
  [agentic-rl专题](./agentic-rl专题.md) 的多轮版本是同一个问题的放大。

▶ 面试题标注：「用 MDP 的语言描述一次 LLM 推理」——照上表走一遍，
主动补这两个特殊性，分数就比背五元组的人高。

## 三、贝尔曼方程：好状态 = 眼前的糖 + 后面的折扣期望

### 3.1 两条公式与一句话直觉

先立三个量：策略 π(a|s) 是给定状态选动作的概率；状态价值 V^π(s) 是从
s 出发、按 π 走下去能拿到的折扣回报期望；动作价值 Q^π(s, a) 是先固定
第一步动作 a、之后按 π 走的折扣回报期望。回报 G_t = Σ_k γ^k r_{t+k}。

贝尔曼期望方程（策略评估的核心）：

`V^π(s) = E_π[ r_t + γ V^π(s_{t+1}) | s_t = s ]`（对所有 s 成立）

写成转移概率显式拆解版（白板推导用这行）：

`V^π(s) = Σ_a π(a|s) Σ_s′ P(s′|s,a) [ r(s,a,s′) + γ V^π(s′) ]`

Q 的最优形式（贝尔曼最优方程）：

`Q*(s,a) = Σ_s′ P(s′|s,a) [ r + γ max_a′ Q*(s′,a′) ]`

一句话直觉：**好状态 = 眼前的糖 + 后面状态的折扣期望**。它把「评估
一个无限长过程」变成「只看一步 + 信任邻居的估值」，一个方程套自己，
自洽条件就是解。手算、策略迭代、value iteration 全都建立在这行字上。

### 3.2 计算题模板：两状态 MDP 手算（本文构造，已验算）

面试官给一个小 MDP 让你算 V，标准流程是「列方程 → 解线性方程组 →
回填数字」。这里的例子照抄即可当面演示：

**题目**：状态 s1、s2 外带终止态 T（V(T) = 0），γ = 0.5，策略 π 为
确定性策略：在 s1 执行动作 a1，环境的转移是 0.5 概率到 s2 拿奖励 1、
0.5 概率直接终止拿奖励 2；在 s2 必然终止，拿奖励 4。

**列方程**：

- `V(s2) = 4 + 0.5 × V(T) = 4`（一步终止，直接落地）
- `V(s1) = 0.5 × (1 + 0.5 × V(s2)) + 0.5 × (2 + 0.5 × V(T))`

**求解**：

- `V(s1) = 0.5 × (1 + 0.5 × 4) + 0.5 × 2 = 0.5 × 3 + 1 = 2.5`

**验算（用回报定义直接推，不套贝尔曼）**：π 下只有两条可能轨迹。

- s1 → s2 → T（概率 0.5）：回报 = 1 + 0.5 × 4 = 3
- s1 → T（概率 0.5）：回报 = 2
- 期望回报 = 0.5 × 3 + 0.5 × 2 = 2.5，与贝尔曼解一致。✓

**这道题对 LLM 的翻译**：s1 是当前前缀，「到 s2」是继续生成、「到 T」
是输出 EOS，reward 4 就是终点 RM 分。RLHF 的 rollout + 折扣回报
累加，本质上就是在对 π 做一次大号的策略评估——只是状态多到没法
列方程组，只能靠采样估。

▶ 面试题标注：写不出方程的人，PPO 讲得再熟也会被一票否决；先写
3.1 的拆解版，再代数字，步骤分全拿。

## 四、价值估计三路线：DP、MC、TD

有了贝尔曼方程，怎么求得 V？三条路线的分歧在于两件事：**需不需要环境
模型 P、R**，以及**每一步用不用别人的估值（bootstrapping，套娃）**。

| 路线 | 需要环境模型？ | 用 bootstrapping？ | 偏差 | 方差 | 典型 |
|---|---|---|---|---|---|
| 动态规划 DP | 需要 | 用 | 低 | 低 | 策略迭代、值迭代 |
| 蒙特卡洛 MC | 不需要 | 不用（等整条轨迹的回报） | 低 | 高 | 首次访问 MC 控制 |
| 时序差分 TD | 不需要 | 用（一步就回步） | 较高 | 低 | TD(0)、Sarsa、Q-learning |

直觉版：MC 是「跑完整条轨迹再算总账」——不偏，但每条轨迹的随机波动
全进估计，方差大，而且必须等到 episode 结束；TD 是「走一步就用邻居
估值把账提前结掉」——不用等结局、方差小，但邻居估值自身有误，所以有偏。
DP 拿完整模型说话，工程上对 LLM 不现实，面试里主要当理论对照组。

**TD(λ) 一句话**：把 n 步回报按 (1−λ)λ^{n−1} 的权重几何加权——
λ = 0 退回一步 TD，λ = 1 退回 MC，中间的 λ 是偏差-方差连续旋钮。

映射到 RLHF 就是 GAE：**本质是 TD 家族搬到 advantage 上的偏差-方差
旋钮**。λ 调大（靠近 1）方差大偏差小、学得快但炸的概率高；调小稳但
学偏。面试官问「λ 和 γ 各管什么」：γ 管「多远的未来算数」（任务
属性），λ 管「掺多少真回报多少 bootstrap」（估计器的工程属性）。

## 五、on-policy vs off-policy：PPO 的尴尬地带

- **On-policy**：用来改进策略的数据，是当前策略亲自采的。更新式里
  的期望对 π 取，样本对得上。**反过来的 off-policy**：数据来自别的
  策略（旧策略、人工、回放池），要靠修正才能用。

教科书里最经典的一对更新式：

| 算法 | 阵营 | 更新式 | 直觉 |
|---|---|---|---|
| Sarsa | on-policy | `Q ← Q + α[r + γ Q(s′, a′) − Q]`，a′ 是当前策略下一步真会选的动作 | 用「我自己下一步的动作」评估 |
| Q-learning | off-policy | `Q ← Q + α[r + γ max_a′ Q(s′, a′) − Q]` | 用「最优的动作」评估，不管我实际会选谁 |

差一个 max，阵营就不同：update 里引用的动作分布（行为策略）和被
改进的分布（目标策略）不是同一个，就是 off-policy。

**重要性采样（IS）一句话**：换成期望的语言，off-policy 的本质是
「想要 E_π 的东西，手上只有 μ 采的样本」——给每个样本加权
ρ = π(a|s) / μ(a|s)，期望就换算回来了；权重分布越飘（两策略差
越远），偏差越小方差越大，这就是 off-policy 复用的代价。

映射到 LLM：

- **PPO 是「有限 off-policy 化的 on-policy」**。rollout 由 π_old 采
  （大几百 token 很贵），一 batch 复用更新 K 步，靠 ρ_t =
  π_θ(a_t|s_t) / π_old(a_t|s_t) 换算；ρ 飘出 [1−ε, 1+ε] 就 clip
  住不再给梯度。**说白了，clip 就是把「可容忍的 off-policy 偏差」关在
  笼子里**——不是步子大小问题，是 IS 换算法差多远的问题。
- **GRPO 系 2025-2026 争的就是 on-policy 程度**：DAPO、Dr.GRPO
  这些变体各自在「复用多少旧 rollout、KL/clip 怎么摆」上重调了
  配比（具体配方见 [rlhf与对齐](./rlhf与对齐.md) 与
  [agentic-rl专题](./agentic-rl专题.md)，本篇只点到）。

## 六、策略梯度：从 REINFORCE 到 advantage

### 6.1 log-derivative trick 推导骨架

策略 π_θ 参数化（就是 LLM 本体），目标是期望回报 J(θ) = E_{τ~π_θ}[R(τ)]。
想把梯度的期望搬到采样里求，用一圈对数技巧：

1. `∇J = ∫ ∇π_θ(τ) R(τ) dτ`
2. 恒等 `∇π = π ∇log π`（log-derivative trick）：`∇J = ∫ π_θ(τ) ∇log π_θ(τ) R(τ) dτ = E[ ∇log π_θ(τ) R(τ) ]`
3. 轨迹概率分解 `log π_θ(τ) = Σ_t log π_θ(a_t | s_t)`（环境里 P 与 θ
   无关，求导后消失——这就是「模型无关」的来源）

最终拿到可采样估计的策略梯度定理形式：

`∇J(θ) = E_π[ Σ_t ∇log π_θ(a_t|s_t) · G_t ]`

**为什么能乘 return**：G_t 只取「t 步之后」的奖励是允许的——t 之前
已发生的 reward 不受 a_t 影响，与 ∇log π 的交叉项期望为零，起
「causality 裁剪」作用，白白降一截方差。

### 6.2 baseline 与 advantage

把 G_t 换成 G_t − b(s_t)，梯度期望**不变**，方差可降。证明一行：

`E[ ∇log π(a|s) · b(s) ] = b(s) · Σ_a ∇π(a|s) = b(s) · ∇(Σ_a π(a|s)) = b(s) · ∇1 = 0`

直觉：∇log π 在概率意义下是「零均值的 noise」，乘一个与动作无关的
常数，积回去还是零；但它影响乘积的方差，选得好能抵消 G_t 里的公共
背景（所有轨迹一起好/一起差的那部分）。

最优的baseline选择是 V^π(s)，于是引入 advantage：

`A^π(s, a) = Q^π(s, a) − V^π(s)`（这个动作比平均水平好多少）

这就是 REINFORCE → REINFORCE with baseline → Actor-Critic 的演化链。

映射到 LLM：GRPO 的**组内均值 baseline（r_i − mean(r_1..r_G)）正是
这一招在 LLM 场景的落地**——没有学 V 网络，就用同 prompt 采的 G 个
样本均值近似 V(prompt)，分子分母都是采出来的、公知识背景被减掉。
面试被问「为什么减组均值不改目标」：把第三行的推导背出来。

### 6.3 案例锚：AlphaGo 三件套——策略梯度 + 价值网络 + 搜索

米哈游 AI 大模型开发一面实录原题「AlphaGo 用了什么强化学习策略」
（见[面经合集二十五节](../../interview-experiences/小红书社招面经合集-2026h2.md)）。
一句话结构：用人类棋谱监督学习练出初始策略网络，再以 REINFORCE 式
策略梯度自我对弈（对局胜负当奖励信号）继续打磨；价值网络估盘面
胜率，蒙特卡洛树搜索（MCTS）拿这层估值剪掉无效分支。

面试三连收获：

- REINFORCE 语义就位：这就是「以终局胜负为回报、按 ∇log π 更新」的
  朴素策略梯度，用 6.1 的骨架现场推一句即可；
- 为什么配 value：纯 MC 要等整局结束才见回报、方差大，价值网络把
  「这步之后还能不能赢」变成即时信号——6.2 的 baseline/估值思想的
  全尺寸落地；
- 与 LLM 的对仗收束：AlphaGo＝策略梯度+价值网络+搜索，LLM 推理
  RL＝策略梯度+RM（价值化）+test-time 搜索，三件套十年没变过，
  被问类比时直接背。

口径：三件套结构为 Nature 2016 论文常识骨架（网络尺寸、rollout 编排
等细节未复核）；出题点为还原帖自报（2026-08 抖音，1007 赞）。

## 七、Actor-Critic 与 PPO：critic 就是个价值模型

**Actor-Critic**：actor（策略 π_θ，产动作）+ critic（估值 V_w，
算 advantage）。教材里 critic 通常小网络；RLHF 把它放大成与 actor
同尺寸的价值模型——PPO 那么重，就是重在这份「双模型 × 双模型
（RM + ref）」的账单上。GAE（第四节的 TD 旋钮）正是 critic 输出的
V 把多步 advantage 串起来的估计器。

**PPO 的两种形态**（目标函数写全才是高分答案）：

- **KL 惩罚版**：`max_θ E[ (π_θ/π_old) Â ] − β · KL(π_old, π_θ)`
  β 按实测 KL 自适应调。把 KL 折进 reward（逐 token 扣 log-ratio）
  或单列进 loss，是工程上的两种等价摆法（拆账差别见
  [rlhf与对齐](./rlhf与对齐.md) 第七节）。
- **Clip 版**（主流默认）：`L^CLIP = E[ min( ρ_t Â_t, clip(ρ_t, 1−ε, 1+ε) Â_t ) ]`
  其中 `ρ_t = π_θ(a_t|s_t) / π_old(a_t|s_t)`。min 的含义只有一句话：
  **当优势已推动的更新让 ρ 飘出信任域 [1−ε, 1+ε]，把额外收益截断
  为零梯度**，防止一次 rollout 被过度榨干。ε 类常取 0.1~0.2。

映射到 GRPO 的一句话：**本质是 PPO 基建（token 级 IS + clip + KL）
配上无 critic 的组内 advantage**。它省的不是哲学，是显存和一个同尺寸
价值模型的训练成本；它付的价是组大小 G 变成新的方差旋钮（G 小则
组均值 base 偏、advantage 噪），以及没有 value 网络在稀疏 reward
下的自磨能力。第六、七节合起来的公式推演，对照
[coding/模型手撕/手写grpo-loss.md](../../coding/模型手撕/手写grpo-loss.md)
亲手推一遍就闭环。

## 八、一表收束：经典概念 → LLM/RLHF 对应物

| 经典概念 | 一句话定义 | LLM/RLHF 对应物 |
|---|---|---|
| 状态 s | 环境的完整刻画 | prompt + 已生成 token 前缀 |
| 动作 a | 决策单位 | 词表里的下一个 token |
| 转移 P | 环境动力学 | 确定性拼接（LLM 特殊性之一） |
| 奖励 r | 环境标量信号 | RM 分数 / 规则验证，稀疏（LLM 特殊性之二） |
| 回报 G_t | 折扣奖励累加 | 一条生成结尾的 RM 分（γ 常取 1） |
| 值函数 V^π | 从 s 出发的期望回报 | PPO 的价值模型（critic 同尺寸副本） |
| advantage A | Q − V，比均值好多少 | PPO 的 GAE；GRPO 的组内分数中心化 |
| on/off-policy | 行为与目标策略是否同源 | PPO/GRPO 复用 rollout 的「有限 off」 |
| 重要性采样 | 换期望的加权重算 | token 级 ρ_t 与 clip |
| TD(λ) | 偏差-方差旋钮 | GAE 的 λ |
| baseline | 免费降方差项 | 组内均值（GRPO）、critic 输出（PPO） |
| 熵奖励 | 防坍缩的正则 | RLHF 里与 KL 同族（防过拟合 RM） |

▶ 面试题标注：被问到任何一个经典概念，先给「一句话定义 + 对应物」，
再挑对应物展开追「为什么不一样」——全场节奏都在你手里。

## ▶ 面试题

**Q1（极高频）：用 MDP 语言描述一次 LLM 推理。**
标准答法：五元组过一遍（第二节表），s = (prompt, 前缀)、a = token、
P 确定性拼接、r 稀疏终奖、γ = 1。然后主动补两个特殊性（transition
确定、reward 稀疏），顺势说「所以 RLHF 选择 model-free 策略梯度路线，
credit assignment 才是核心难题」——把答案带到自己准备过的地盘。

**Q2（高频）：transition 确定性这一点，实际省了什么？**
省掉的是 model-based 那一票工程：不用学世界模型、不用担心动力学
估偏把策略带沟里去，P 在策略梯度推导里对 θ 求导直接消失（第六节
骨架第 3 步）。代价是省不掉 reward 端的复杂——RM 照样要训、终奖照样稀。

**Q3（高频）：贝尔曼方程，这两个状态的 V 算给我。**
白板标准流程：① 写拆解版 `V(s) = Σ_a π(a|s) Σ P [r + γ V(s′)]`；
② 先算「一步终止」的状态落地；③ 回填带期望的方程；④ 用「枚举
轨迹的期望回报」独立复算一遍（3.2 节的例子直接套用：V(s2) = 4、
V(s1) = 2.5）。先列方程再代数字，别倒着做。

**Q4（高频）：MC 和 TD 怎么选？GAE 的 λ 到底调什么？**
MC 不偏不倚但要等整条轨迹、方差大；TD 提前用邻居估值结账、省等待
但有偏。λ 是谱系上的旋钮不是开关：λ → 1 偏 MC 风味、λ → 0 偏
一步 TD。追「γ 和 λ 区别」——γ 是任务本身「多远的未来算数」，
λ 是估计器「掺多少真回报多少 bootstrap」，两个量各管各。

**Q5（高频）：PPO/GRPO 算 on-policy 还是 off-policy？**
一句话答不出满分，要画光谱：纯 REINFORCE 是严格 on-policy；PPO
加 IS + clip 允许 batch 复用 K 步，是「有限信任域的 off-policy」，
偏差被 clip 按住；再往远走是经验回放、IMPALA 式的大 off-policy，
LLM RL 暂不通行。异步 rollout 把「有效 off 度」又拉大一截——
DAPO、Dr.GRPO 在 token 级 clip / 双侧截断上重调配比正是对此。

**Q6（高频）：为什么 baseline 不调期望、却降方差？**
要能在白板上写三行：`E[∇log π(a|s)] = Σ_a ∇π = ∇1 = 0`，所以
`E[∇log π · b(s)] = 0`，bias 不变；但乘积的方差随 b 选择而变，
把跨样本公共波动减掉。最优解是 V^π(s)——这正好是 advantage
的诞生动机。顺带一句：GRPO 的组内均值把同一个推导搬过来，免
训练一个 V 网络。

**Q7（中频）：REINFORCE 没什么毛病，为什么要 Actor-Critic？**
毛病只有方差太大——稀疏终奖下一个 G 标量同时去推/拉全部 token
的 logprob，噪声盖过信号；critic 给的 V 把公共背景扣掉、TD 把
等待变短，advantage 信噪比立刻上来。LLM 场里这一点被 reward
稀疏放大，所以纯 REINFORCE 路线在 RLHF 里从未当主力。

**Q8（中频）：PPO clip 的直觉到底是「防大步」还是别的？**
正确口径是「防同一份 rollout 被过度复用」——信任域罚的是 ρ 漂离
1，不是学习率的大步。追问区别：如果每步都重新 rollout（严格
on-policy、K = 1、π_old = π_θ、ρ 恒 1），clip 完全不生效也能训，
只是贵到没人这么干——答到这层，「稳定器」与「off-policy 妥协」才统一。

**Q9（中频）：GRPO 不用 critic 靠什么算 advantage？代价是什么？**
靠同 prompt 内 G 个样本的组内均值当 baseline：
`A_i = r_i − mean(r_1..r_G)`（再除组 std 做归一）。省掉同尺寸价值
模型的显存与训练成本；代价有二：① 组均值在小 G 下噪声大，G 成新
旋钮；② 全 0 / 全 1 组 advantage 退化为零梯度，稀疏 reward 下
占比高，多轮版见 [agentic-rl专题](./agentic-rl专题.md)。
