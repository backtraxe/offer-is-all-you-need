# 面试四周冲刺自检清单：把全仓变成一份行动手册

> 本篇是仓库的「终点页」——学完所有内容后，用这张清单把知识变成
> 行动和结果。开通本页之前应先读完
> [resources/学习路线图](../resources/学习路线图.md) 与
> [知识串联与why链](./知识串联与why链.md)。本页每两周修订一次，
> 随面经与行情更新。

## W1（第 1 周）：地图与手感

- [ ] 一句话地图：要素过一遍
  [知识串联与why链](./知识串联与why链.md)，能画出五条因果链
- [ ] 项目白名单：锁定主副件（参考
  [projects/项目篇章导读](../projects/README.md)「四、项目选型总表」），
  确定 4 周交付范围（**只宣砍，不加**）
- [ ] 手撕热身：leetcode hot 100 核心 30 题过一遍
  （链表/二分/滑窗/DP/回溯/LRU）；复写 multi-head attention +
  KV block manager[两遍](https://leetcode.com/problemset/)
- [ ] 开场包：30s/2min/5min 三版自我介绍录音自听两遍
  （参照 [沟通与 HR 面专题](./沟通与hr面专题.md) 第一节）；
  离职原因三段式文字稿
- [ ] 简历 1.0：按 [resume/](../resume/README.md) 出母版，
  三遍防造假三问，完了发给两个朋友红笔圈一圈
- [ ] 反馈：写完面试日记——哪三处答不出来（拿三问清单）

## W2（第 2 周）：专项突破

- [ ] 推理 infra 研报：[推理 Infra 社招面经与备战](./inference/推理infra社招面经与备战.md)
  九宫格过三遍，把「八类项目追问」映射回你的主项目
- [ ] 推理技术栈：[vllm与推理加速核心](./inference/vllm与推理加速核心.md)、
  [长上下文推理与kv体系](./inference/长上下文推理与kv体系.md)、
  [显存计算专题](./显存计算专题.md)（算显存三个实例题亲手推）
- [ ] RLC 实战：[rl训练工程实战](./训练与对齐/rl训练工程实战.md)：

  四坑+四维巡检一图能默写，数字锚能对答
- [ ] Agent 全景：[34 题题库对照](../interview-experiences/小红书社招面经合集-2026h2.md)
  + agent/ 目录八篇轮一遍，记 10 条追问
- [ ] 工程八股：[工程基础八股专题](./工程基础八股专题.md) 五大桶
  「三句+为什么+案例」逐格过
- [ ] 压力自查：用 [工程基础八股专题](./工程基础八股专题.md) 
  第八节两场景题互助口答，最快不超过 90s 给骨架

## W3（第 3 周）：模拟面试与面序

- [ ] 三场模拟：一个技术、一个项目深挖、一个 HR/主管面
  （欢迎用大模型/朋友扮演面试官；项目深挖参考
  [projects/README.md](../projects/README.md) 「书写器三问」）
- [ ] 面序博弈定案：按 [沟通与hr面专题](./沟通与hr面专题.md) 第六节，
  定下投递梯队（先中下游攒 offer → 反哺目标厂 → 最后收源头厂）
- [ ] 投递看板：列好 投递/约面/进行中/二面/offer/拒信 六栏，
  每行含 JD 锚点关键词（对齐仓内两份 [jd分析](../resources/)）
- [ ] 公司深挖：每个目标厂花 30 分钟看其技术博客/开源项目（对照
  [推理infra社招面经与备战](./inference/推理infra社招面经与备战.md) Q4 标准）
- [ ] 材料终验：问三问、GitHub 仓库 README+数据、自我介绍录音、
  offer 变量表（现包/期望/最低可接）
- [ ] 日志：第三周结束，简历 v2.0——把被拒/未约的反馈逐个写回

## W4（第 4 周）：面试周执行

- [ ] **面试前夜包**：JD 重点三行 / 简历同版 PDF / 三问材料的复述提纲 /
  主机+备忘录+备用热点
- [ ] **当日三段**：提前到场 / 开场介绍响亮（贴脚）/ 当场记录
- [ ] **结束 15 分钟复盘**：面卡填完——问了什么、答得怎样、哪里
  被追深、如果再来一次怎么答；晚上更新到投递看板
- [ ] **爆冷处理**：答崩一题不补，接下一题；结束时感谢并问一句
  「您能给我指出一个最需要加强的点吗」
- [ ] **多面联动**：下轮面试前回看上一轮的复盘——**字节面评连贯**
  会接着问（仓内面经注明）
- [ ] **offer 博弈**：到手 offer 记档（现包/带宽/审批层级）；
  谈判阶段对照 [沟通与hr面专题](./沟通与hr面专题.md) 六、七节

## 整日三问审查（每做一次上台前复查）

1. **材料三问**：简历这条项目——特有难点 / 按能力配比 / 记住
   分项短板，能答吗？
2. **口述三问**：这道题——经典三句 / 为什么 / 生产案例，能成吗？
3. **数字三问**：这个指标——口径 / 环境 / 我今天还能复测吗？
