## 三、两条岗位主线怎么选

调研结论（详见两份 JD 分析）：

- **都不要偏废软件工程底盘**：95% 的 Agent 岗 JD 仍要求 API/并发/Docker/云；
  推理岗第一语言偏向 C/C++，训练岗偏向 Python。
- **分线信号**：
  - 你更在意"把模型能力变成产品"→ 走 Agent 开发线：RAG → ReAct/MCP/记忆 → Eval 与生产化。
  - 你更在意"让模型又快又省"→ 走 AI Infra 线：vLLM/CUDA/量化 → 3D 并行/ZeRO/NCCL。
- **交汇点**：训练对齐（SFT/RLHF/GRPO）两条线都要懂概念；RL Infra 等新兴高薪岗
  要同时熟悉 vLLM 与 Megatron，是 2026 的差异化竞争力。

## 四、JD 调研给出的 5 条备战启示

1. **RAG/框架名词只是门票，「生产化证据」才是入场券**：21/21 的 Agent 岗 JD 要求可验证项目。
   把项目从 Demo 升级为可上线系统：评测集、Tracing、失败降级、成本指标。
2. **准备「稳定性叙事」而非「功能叙事」**：高频追问全是失效模式——Agent 死循环、
   工具调用失败分类、检索没召回 vs 模型乱编、评测集怎么构造。
3. **2026 新分水岭**：MCP（18/21 JD 提及）、Eval/可观测性、重度使用 AI Coding 工具
   （DeepSeek 把 Claude Code/OpenClaw 深度使用列为硬性要求）。
4. **Infra 方向简历必须写「规模数字」**：100B+ 模型、千卡集群、X tokens/s、MFU 从 A% 到 B%。
   没有大集群就用小集群复刻 + 开源 benchmark 数字。
5. **给 vLLM/SGLang/Megatron 提 PR 是 Infra 最高性价比加分项**：腾讯/字节/Moonshot
   多家 JD 显式点名。

## 五、使用方法

1. 先读两份 [JD 分析](./jd分析-agent开发岗.md)，确认自己的目标岗位画像。
2. 按本路线图的阶段顺序刷 [interview-questions](../interview-questions/README.md)
   考点地图；每章配套 [coding](../coding) 手撕练习。
3. 学习资源（书单/仓库/B 站/博客）汇总在 [学习资源清单](./学习资源清单.md)。
4. 面一家公司前，先查 [面经复盘](../interview-experiences) 有没有对应案例，
   再过一遍对应阶段的 Top 题。

## 六、12 周备战日历（校招 / 社招双版本）

> 阶段表给的是「学什么」，这张日历把 5 个阶段落到 12 周。与
> [面试四周冲刺自检清单](../interview-questions/面试四周冲刺自检清单.md)
> 的关系：本表是全周期，冲刺清单是最后 4 周的压强版，收尾时执行。

### 校招版（全职备战，每周 40+ 小时）

| 周 | 主线任务 | 验收 |
|---|---|---|
| W1-2 | L0+L1：basics 八篇连读 + llm基础 | 徒手画 Transformer、KV 显存手算 |
| W3-4 | 选定主线（Agent 或 Infra），对应专题过一轮 | 术语全通，能讲每条因果链 |
| W5-6 | 项目增量改造（projects/ 选型）+ coding 频次表上半 | 项目达到「可追问」状态；频次表 Top10 默写过半 |
| W7-8 | 专题深挖（RL/推理引擎/mcp 按主线）+ 追问链整理 | 每个专题 ▶ 面试题自答一遍并录音 |
| W9-10 | [模拟面试两套卷](./模拟面试与口语化表达.md) + 系统设计 + 面经定向 | 每题 90 秒四拍；目标公司速查表背熟 |
| W11-12 | 冲刺清单 W1-W4 + 投递面试滚动 + [复盘四步法](./挂后复盘四步法.md) | 面试日记闭环，补丁当日入库 |

### 社招版（在职骑驴，每周约 10 小时）

| 周 | 主线任务 | 验收 |
|---|---|---|
| W1-2 | 自我审计（对着 [考点地图](../interview-questions/README.md) 标红白黄）+ 简历 1.0 | 缺口清单成形；简历过防造假三问 |
| W3-6 | 只攻红色区专题 + 项目包装（现项目×新技术结合） | 项目经得住三连追问；红色区降到黄色 |
| W7-8 | coding 频次表 + 目标公司面经定向 | 新题型（GRPO Loss/KV 公式）能默写 |
| W9-10 | 模考卷 + 小范围投递试水（3-5 家练手） | 练手场下来的补丁当日闭环 |
| W11-12 | 主力投递 + 谈判牌面盘点 | 按 [投递与offer实战](./投递与offer实战.md) 四要素出牌 |

**执行纪律**：社招版每周日晚做 30 分钟计划校准（本周补丁哪些、
下周主攻什么）；校招版每两周用冲刺清单的任务卡抽查自己一遍。
