# 投递与 offer 实战：时间线、渠道、面评管理与谈判

> 面向：已经「会考试」但未必「会找工作」的候选人。仓库其余篇章解决
> 「面试怎么赢」，本篇解决「仗怎么安排」——时间线、投递渠道、笔试
> 形态、面评推进、薪资谈判、offer 选择。行情判断以 2026-10 面经调研
> 为准（多为单帖口径，热点窗口每年平移）。

## 一、时间线：校招与社招的两张日历

### 校招（以 27 届为例，年份平移）

```text
研二下 3-6月   暑期实习投递（转正率最高的通道，「有基选基」）
研二暑期       实习 + 提前批锁定（6-8月各家提前批陆续开）
研三上 8-10月  正式批主战场（金九银十，笔试面试密度峰值）
研三上 11-12月 补录与捡漏（毁约释放的 HC，门槛反而松）
```

要点：**实习转正 ≫ 提前批 > 正式批 > 补录**。面经评论区楼主的实习
冷启动路径是「小公司热门方向或大公司边缘方向起步，靠实习找实习」。

### 社招

```text
全年滚动，但金三银四 / 金九银十 HC 密度最高
裁员潮后 1-2 个月是供给洪峰（竞争烈度上升，但公司端捡漏心态也强）
基模社招窗口明显收窄：同梯队要求 + connection 权重高（851赞行情帖口径）
```

校招还有「人才期权溢价」，社招纯看即战力——**基模帖子结论：校招有
基选基，社招优先核心业务组**。

## 二、投递渠道与内推获取

| 渠道 | 适用 | 要点 |
|---|---|---|
| 官网/公众号投递 | 正式批主通道 | 走流程最稳，但简历关依赖关键词匹配，按 resume/ 篇埋词 |
| boss 直聘/脉脉 | 社招与实习 | 直接对话招聘方，适合问清「真 HC 还是刷 KPI」 |
| 内推 | 全场景最高优先 | 面评可追踪、流程可加急；来源：师兄、前同事、技术社区群主 |
| 捞人帖（小红书/即刻） | 实习与急招岗 | 面经调研中「阿里 27 届 Infra 捞人」「淘天秋招冲刺」「清华系招推理优化」都是真实 HC 信号，评论区直接问 |
| HR 主动联系 | 简历挂 boss 后被动流量 | 甄别外包与凑数面试：先问团队、汇报线、HC 审批状态 |

**识别真 HC 三问**：这个 HC 是新增还是替补？汇报给哪个团队负责人？
流程大概几轮、周期多久？答不上来的约面多半是刷 KPI。

## 三、测评与笔试形态（2026 换轨中）

- **传统 ACM 式算法笔试在退潮**：DeepSeek 社招笔试已把 ACM 题换成
  系统设计题（43 赞帖口径），「读代码改代码比写代码重要」。
- **coding 测评线下移**：更多公司用手撕视频会议 + 共享屏幕替代
  统一笔试；手写题按 [coding/刷题频次映射表](../coding/刷题频次映射表.md) 刷。
- **AI 辅助笔试出现苗头**：允许甚至考察使用 AI Coding 工具完成任务
  的岗位在增加——和「AI Coding 经验成考察方向」（硕一帖信号）同一条线。
- **行测/性格测评**：大厂保留项目，别裸考，两天足够熟悉题型。

## 四、面评管理与流程推进

各家轮次职能有稳定分工（米哈游帖的三段式最典型）：

```text
一面「会不会做」：基础核验 + 项目真实性（检测仪：细节追问）
二面「能不能设计」：架构 + 场景 + 业务匹配（决策权最大的一轮）
三面/HR「适不适合」：业务认知 + 稳定性 + 薪资意愿
```

操作要点：

- **每场面完 30 分钟内写面试日记**：原话级记录被问倒的题，当晚
  分类到专题文档（方法见 [挂后复盘四步法](./挂后复盘四步法.md)）。
- **横向对比是常态**：「43 投 43 挂泡池子」帖说明被横向不等于挂——
  横向期保持每周一封进度询问邮件/微信，频率别超过一周一次。
- **一面挂别慌着否定自己**：多位楼主复盘「保底组一面挂、梦中情组
  走到最后」，面评是分布不是判决。
- **催进度的正确姿势**：问「当前流程卡在哪一环，是出于 HC 审批
  还是横向对比」，信息量比「有消息吗」大十倍。

## 五、薪资谈判（硕一帖四要素 + 行情结构）

谈判筹码按权重排序（21 司 44 轮 5offer 楼主口径）：

1. **面评**：最高权重——同一个人不同面评的报价可以差一档；
2. **竞对 offer**：但「不同公司的 offer 并不具备完全对称的议价能力」，
   更高报价未必能推动更大平台突破带宽；
3. **岗位带宽**：职级决定天花板（140 问帖锚点：那批 14 家一般
   2-1 到 2-2）；
4. **时序**：先拿小厂 offer 垫底、大厂流程后置，注意 offer 有效期
   与拖字诀的风险。

结构陷阱（基模行情帖）：待遇 double 是底线，但常靠**两年期大模型
相关激励**拉高——过期不续的话落差很大，谈的时候问清「固定部分
占比、激励兑现条件、续约条款」。算账方法论见
[简历篇算账学](../resume/我的简历母版.md)。

整理，单帖口径；「X 计划」名册即厂内 SSP 定级通道，拿计划≈高定级
高包裹的显式标记。

| 云弧人才计划 | 拼多多 | 已发意向、是否定档云弧未通知 |
| KStar | 快手多模态 | HR 面后泡池子 |
| 飞星计划 | 科大讯飞基模 | 二面进度 |
| AMU | 百度 | 同场有二面挂点 |
| TStar / 阿里星 / 部门星 | 阿里（淘天/QwenC 等） | TStar 四轮技术面起、更高定级再加面 |

三条硬口径（单帖/评论自报，待开奖季多帖互证）：

- **转正不可当大饼**：楼主实习转正挂、七分钟沟通定性半年实习，
  六月即启动秋招是「先见之明」级时间线教训；
- **学历硬门槛集中在头部厂**：楼主口径「硬卡学历的基本只有阿里，
  非 9 本有点难；学历直接影响横向对比与定薪」；
- **人才计划 offer 极稀缺**：评论区估算「最多的应该有 100+」，别按
  计划名做保底假设。完整 17 家进度清单见
  [面经合集二十六节](../interview-experiences/小红书社招面经合集-2026h2.md)。

## 六、offer 选择框架

按 2026 行情，排序建议：

1. **赛道分层**：基座（稀缺高薪、K 型分化、同梯队壁垒）> 核心业务
   Agent/应用（需求大、成长快）> 普通 infra（岗位供给过剩、内卷，
   「高薪陷阱」帖口径）> 边缘业务。
2. **团队 > 平台 > 薪资**：基模帖的原话是「进了嫡系圈才碰核心训练」，
   赛马文化重的组「一边干活一边研究跑路是常态」——面试反问时
   直接问「我在前六个月会做什么项目、向谁汇报」。
3. **业务优先级信号**：面试官能不能说清团队的交付压力和 metrics；
   说不清的组，进去大概率当螺丝钉。
4. **WLB 与身体**：「核心团队+交付压力=除了吃饭睡觉就是干活」，
   评估自己能不能扛两年。
