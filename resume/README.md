## 简历的两条硬事实

1. **初筛是秒级战场**：HR/技术筛一份简历的平均耗时以秒计（面试官自述
   「大部分简历看完三个地方就定」），简历第一屏（基础信息 + 个人优势 +
   最近一段经历）决定是否被读完；
2. **面试官靠简历出题**：你写的每个项目名、每个指标，都会变成下一轮
   面试的追问源——写夸大 = 给自己挖坑；写「烂大街爆款没改造」，
   等于自报「我没独特点」。**简历上的每个字要么换来面试机会，要么
   换来连环追问**，二选一。
