## 答题建议

1. **前 3 分钟先澄清**：规模（DAU/QPS/文档量）、权限、时延要求、评测口径——
   直接开画架构图是新手信号。
2. **指标贯穿全篇**：2026 追问主线是"怎么量化"，每个设计决策落到一个
   可测指标（口径 + 获取方式），不要停在"效果好"这种空话。
3. **预留一个真实失败案例**：每道设计题的"追问预案"都假设你会被问到
   "这个方案挂过一次，什么原因？"——提前想好你的版本。
4. Infra 类设计题的容量估算可以背模板：DAU × 请求/人 × token/请求 →
   峰值 tokens/s → Little's Law 并发 → 单卡产能 → 卡数 → KV Cache 核对。
